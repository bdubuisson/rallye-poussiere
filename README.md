# Rallye Poussière

Petit jeu de course tout-terrain en vue isométrique, jouable à 1 ou 2 joueurs (plus des voitures pilotées par l'ordinateur) sur un circuit en terre avec tremplins, bosses et flaques de boue.

**Jouer :** https://bdubuisson.github.io/rallye-poussiere/

## Commandes
- **Joueur 1 (rouge)** : Z Q S D (W A S D en QWERTY) + nitro Maj gauche
- **Joueur 2 (bleu)** : flèches + nitro Entrée
- Manettes : A = gaz, B = frein, X/RB = nitro
- Tablette : accélération automatique, ◀ ▶ pour tourner, les deux ensemble pour reculer, 🔥 = nitro
- Échap = menu, M = son

Un seul fichier `index.html`, sans dépendance : il suffit de l'ouvrir dans un navigateur.
