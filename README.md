# Rallye Poussière

Petit jeu de course tout-terrain en 3D (three.js), jouable à 1 ou 2 joueurs en écran partagé, plus des voitures pilotées par l'ordinateur, sur un circuit en terre avec tremplins, bosses et flaques de boue. Caméra 3/4 qui suit la voiture ou caméra de poursuite (touche C). Collisions de corps rigides : les voitures pivotent selon le point d'impact.

**Jouer :** https://bdubuisson.github.io/rallye-poussiere/

## Commandes
- **Joueur 1 (rouge)** : Z Q S D (W A S D en QWERTY) + nitro Maj gauche
- **Joueur 2 (bleu)** : flèches + nitro Entrée
- Manettes : A = gaz, B = frein, X/RB = nitro
- Tablette : accélération automatique, ◀ ▶ pour tourner, les deux ensemble pour reculer, 🔥 = nitro
- C = caméra, M = son, Échap = menu

Un seul fichier `index.html` (three.js r128 chargé depuis cdnjs) : il suffit de l'ouvrir dans un navigateur.
